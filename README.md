Memory Management Simulator

About the Project

The Memory Management Simulator is a web-based Operating System mini-project. It demonstrates how an operating system allocates memory to processes using different memory allocation algorithms.

Objectives

- To understand memory allocation in operating systems.
- To implement First Fit, Best Fit, and Worst Fit algorithms.
- To compare memory allocation results.
- To visualize allocated memory and remaining memory.

Features

- Simple and user-friendly website.
- Input custom memory block sizes.
- Input process sizes.
- Simulate First Fit, Best Fit, and Worst Fit algorithms.
- Display allocation results for each process.
- Show remaining memory in each block.
- Compare the results of all three algorithms.

Technologies Used

- HTML
- CSS
- JavaScript

Algorithms Implemented

1. First Fit

Allocates a process to the first memory block with sufficient available space.

2. Best Fit

Allocates a process to the smallest memory block that can accommodate it.

3. Worst Fit

Allocates a process to the largest memory block that can accommodate it.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "memory_management.html" in a web browser.
4. Enter memory block sizes and process sizes, separated by commas.
5. Click Simulate Allocation to view the results.

Sample Input

Memory Blocks (KB): 100, 500, 200, 300, 600

Process Sizes (KB): 212, 417, 112, 426

Expected Output

The website displays the allocation results for First Fit, Best Fit, and Worst Fit. It also shows the selected memory block, allocated processes, and remaining memory.

Applications

- Learning operating system concepts.
- Understanding memory allocation algorithms.
- Comparing different allocation strategies.

Conclusion

This project provides a simple interactive demonstration of memory allocation techniques used in operating systems. It helps students understand how different algorithms allocate memory to processes.
