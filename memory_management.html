About Memory Management

Memory management is an operating system function that allocates and manages memory for running processes.

Algorithms Used

First Fit: Selects the first block large enough.

Best Fit: Selects the smallest suitable block.

Worst Fit: Selects the largest suitable block.

Important Terms

Process: A program being executed.

Memory Block: A section of available memory.

Internal Fragmentation: Unused space inside an allocated block.
